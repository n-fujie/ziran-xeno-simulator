Meta-Configuration M

Explicitly represented and partially revisable meta-configuration: the registries that decide what can count as a value kind, a description facet, a transition class, an observation-revision candidate, a grammar mutation, a comparison metric, an emergence feature, a Pareto axis, a trace schema or a benchmark predicate. Level D (Mt → Mt+1) changes some of these during a run; the registry interfaces and the code consulting them remain fixed. This does not remove constraints — it makes some of them inspectable.

What this is

Ziran / Xeno Operational World Simulator is an experimental framework for studying how operational differences ignite under configuration-dependent conditions, alter downstream reachability, penetrate across coupled configurations, and reorganize observation and description systems.

The current release supports explicit analysis of configuration reorganization, description-space transformation, and partially revisable meta-configuration. Its benchmark results are synthetic and are not empirical validation of the underlying theoretical framework.

An open research prototype (v0.3.0) — not a completed theory implementation, not an empirically validated theory, not an unrestricted autonomous-science system, not an ontology-free simulator, not a historical-person simulator.

Ct → Δt → ignition → operation → real effect → penetration → feedback → reorganization → Ct+1

The core knows only

  • storage addresses holding opaque operational values (scalar, vector, relation, event, opaque, unknown or registered kinds), separated from operational addresses,
  • an open configuration of dimensions that can appear, disappear, split, merge, change resolution,
  • clocks (no global simulation clock),
  • ignition rules (condition → operation, with delay),
  • couplings along which differences penetrate (delay, transform, loss, medium),
  • observation apparatuses (several; none privileged) whose non-detections are classified, never read as absence,
  • probes (possibilities) whose reachability is computed by forking the world,
  • and the trace.

A / B / C / D

A/B/C/D are not ontological strata. They are revisable analytical distinctions used to localize different forms of operational change. A higher letter is not a deeper reality, a superior explanation or a more advanced intelligence.

  • Level A — operation within C (real effects).
  • Level B — Ct → Ct+1: reorganization of the configuration within the same description space.
  • Level C — St → St+1: open but meta-bounded description-space morphogenesis — descriptors appear or disappear within the registered facets.
  • Level D — Mt → Mt+1: explicitly represented and partially revisable meta-configuration — facets, value kinds and other registry entries are registered or retired.

Terminology

  • Probe-relative reachability (implemented) vs emergent reachability (description-space change in the same forks; implemented as a first mechanism, not unrestricted).
  • Grammar-bounded variable discovery (baseline) vs operator-grammar morphogenesis (the construction grammar changes; the meta-operations themselves are fixed code).
  • Historically constrained operational reconstruction — never person simulation; generated behaviour is simulation-internal.
  • Horizon-relative closure — not demonstrated irreversibility.
  • Meta-grammar morphogenesis — mutation operators are data; recurring sequences can be composed, abstracted, retired. Not unrestricted grammar generation.
  • All results in this repository are synthetic. The external adapter can replay recorded data as configuration-bound observations; none is bundled.
  • Storage values are opaque operational values; numbers are one kind, handled by a scalar adapter.

Humans, agents, bodies, markets, beliefs, goals, capabilities, sciences and philosophies are not in the core. Domain layers compose them from these positions; categories are introduced where they produce non-redundant operational differences, and the analysis modules test when that is the case (benchmarks J and K show both outcomes).

Stopping principle

A fixed condition is not automatically a theoretical defect. It becomes a new experimental object only when changing it produces a non-redundant difference in observation, intervention, reachability, real effect, penetration, feedback, reorganization or the interpretation of the result.

Reading the interface

Nodes are events and differences, not persons or concepts. Every number links back to trace events; every event links to its upstream causes and downstream penetration.
